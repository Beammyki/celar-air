# Celar Air — เว็บไซต์บริการล้างแอร์

เว็บไซต์ประชาสัมพันธ์บริการของ **Celar Air** สำหรับลูกค้าในนครปฐมและพื้นที่ใกล้เคียง ออกแบบให้ใช้งานง่ายบนมือถือและเดสก์ท็อป พร้อมเนื้อหาบริการ ผลงานจริง ขั้นตอนการทำงาน รีวิว คำถามที่พบบ่อย และบทความดูแลเครื่องปรับอากาศ

## ฟีเจอร์หลัก

- หน้าแรกพร้อม hero section และภาพพื้นหลังโทนฟ้าอากาศสะอาด
- หน้าบริการ ราคา เกี่ยวกับเรา และติดต่อเรา
- ขั้นตอนการทำงานพร้อมภาพผลงานจริง
- แกลเลอรีผลงานก่อน–หลังล้างแอร์แบบเลื่อนและเปิดดูภาพขนาดใหญ่ได้
- ส่วนรีวิวลูกค้าและบทความความรู้เรื่องแอร์
- FAQ แบบ accordion
- โมเดล 3D เครื่องปรับอากาศสำหรับดูส่วนประกอบภายในและคำอธิบายการทำความสะอาด
- ปุ่มติดต่อ LINE และโทรศัพท์แบบลอยอยู่ด้านขวาของหน้าจอ
- รองรับการแสดงผลแบบ responsive และมี motion ตอนเลื่อนหน้า

## เปิดดูในเครื่อง

โปรเจกต์นี้เป็นเว็บไซต์แบบ static ไม่ต้องติดตั้ง backend

```powershell
python -m http.server 8765 --directory dist
```

จากนั้นเปิด [http://127.0.0.1:8765/index.html](http://127.0.0.1:8765/index.html)

## โครงสร้างโฟลเดอร์

```text
dist/                 ไฟล์เว็บไซต์ที่พร้อม deploy
dist/assets/          รูปภาพ โมเดล 3D และภาพพื้นหลัง
dist/index.html       หน้าแรก
dist/services.html    บริการ
dist/prices.html      ราคา
dist/about.html       เกี่ยวกับเรา
dist/contact.html     ติดต่อเรา
dist/gallery.js       แกลเลอรีและ lightbox
dist/air-explorer.js  ตัวควบคุมโมเดล 3D
dist/footer.js        footer ที่ใช้ร่วมกันทุกหน้า
dist/floating-contact.js  ปุ่มโทรและ LINE แบบลอย
```

## เผยแพร่เว็บไซต์

### GitHub

โปรเจกต์นี้สามารถเปิดดู source และประวัติการแก้ไขได้จาก GitHub repository ของ Celar Air

### Cloudflare Pages

ใช้โฟลเดอร์ `dist` เป็นโฟลเดอร์สำหรับเผยแพร่ เว็บไซต์ static สามารถใช้งานบน URL ฟรีของ Cloudflare Pages ในรูปแบบ `*.pages.dev` ได้ โดยไม่ต้องมีเซิร์ฟเวอร์เพิ่มเติม

หากต้องการใช้ `celarair.dev` หรือ `www.celarair.dev` ต้องมีโดเมนดังกล่าวอยู่ในบัญชีของคุณก่อน แล้วจึงเพิ่ม DNS record ตามค่าที่ Cloudflare แสดงให้ในหน้าตั้งค่าโดเมน
